# Creator Launch

A responsive, conversion-focused landing page concept for a digital course. The project demonstrates offer positioning, curriculum presentation, responsive design, interactive accordions, and a checkout-ready call to action.

## Live demo

[View Creator Launch](https://creator-launch-portfolio-josea.josealvesfb424.chatgpt.site)

## Features

- Responsive desktop and mobile layout
- Conversion-focused offer hierarchy
- Interactive course curriculum
- Product benefits and bonus presentation
- Demo checkout interaction
- Accessible semantic HTML

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

Open `index.html` in a web browser. No build process or dependencies are required.

## Deploy with GitHub Pages

1. Upload the repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save**.
